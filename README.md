SURVIVAL ARENA

実行環境の必要条件

python >= 3.10

pygame >= 2.1

ゲームの概要

画面中央のプレイヤー（青色の丸）を操作し，四方から次々と出現して追いかけてくる敵（赤色の丸）から逃げ続ける2D見下ろし型サバイバルゲーム。

制限時間120秒間生き残ることを目指す。

ゲームの遊び方

W / A / S / D キー：プレイヤーキャラクターの上下左右移動

R キー：ゲームオーバーまたはクリア画面でゲームをリスタート

ESC キー：ゲームを終了

ゲームの実装

共通基本機能

背景およびプレイヤー，敵キャラクターの描画

WASDキーによるプレイヤーの移動制御（斜め移動の速度正規化および画面外への移動制限）

画面外からの敵のランダム生成およびプレイヤー追尾処理

プレイヤーと敵の当たり判定（接触時のHP減少処理および無敵時間・点滅制御）

画面上部へのHP，生存時間（スコア），残り時間の表示

HPが0になった際のGAME OVER表示，120秒生存時のCLEAR表示，リスタートおよび終了機能

分担追加機能

ダッシュ機能（担当：メンバー1）：SHIFTキー押下時にプレイヤーの移動速度を一時的に上昇させる機能

爆弾機能（担当：メンバー2）：SPACEキー押下で画面内の敵を一括排除する機能

シールド機能（担当：メンバー3）：Eキー押下で一時的に敵からのダメージを無効化するバリアを展開する機能

アイテム機能（担当：メンバー4）：フィールド上に回復やスコア加算アイテムを出現・取得させる機能

特殊な敵の追加（担当：メンバー5）：速度や移動パターンの異なる新しい種類の敵を追加する機能

メモ

コードは main.py の単一ファイル構成とし，オブジェクト指向（Player, Enemy, Game クラス）で設計されている。

実行時の作業ディレクトリを固定するため，スクリプト先頭に os.chdir(os.path.dirname(os.path.abspath(__file__))) を記述している。

メンバーごとの追加機能実装を円滑に行えるよう，各クラスおよび関数に型ヒント（Type Hints）とdocstringを明記している。
